# 发布检查单

## 1. 范围与授权

- [ ] 明确本次是虚构 demo、内部 studio 还是 recipient 交付。
- [ ] GitHub 仓库保持 private，除非完成公开源码和素材授权评审。
- [ ] 所有人物、文本、媒体、音乐和字体均有可记录的使用授权。
- [ ] 没有把真实客户内容放进 Issue、PR、提交历史、CI 日志或 Actions artifact。
- [ ] 没有把静态口令描述成登录、加密或安全访问控制。

## 2. 工作树与质量门禁

- [ ] 审阅 `git status --short` 和完整 diff，只包含本次预期修改。
- [ ] `pnpm install --frozen-lockfile` 成功。
- [ ] `pnpm validate:instances` 通过。
- [ ] `pnpm test` 通过。
- [ ] `pnpm privacy:check` 通过。
- [ ] 目标实例的 `pnpm build` 通过。
- [ ] `pnpm build` 内置的成品隔离检查通过。
- [ ] 浏览器控制台没有错误，键盘、窄屏、减少动态效果和完整章节流程已检查。

## 3. 成品隔离

- [ ] `dist/` 只包含当前实例声明的素材。
- [ ] 搜索 `dist/`，确认没有其他实例名、人物称呼、本机路径或开发提示。
- [ ] recipient 构建不包含制作台入口或制作台代码块。
- [ ] 页面标题、描述、分享图、口令提示和结尾声明属于当前实例。
- [ ] 成品体积和首屏素材符合本次交付预算。

## 4. 部署安全

- [ ] 公开地址只承载虚构 demo；真实数据已置于有服务端鉴权的环境。
- [ ] HTTPS、CSP、Referrer Policy、frame 限制和 MIME sniffing 防护已配置。
- [ ] 搜索索引、CDN 缓存、日志、错误追踪和分析工具不会泄露私人内容。
- [ ] 访问撤销、内容删除、备份恢复和事故联系人已经明确。
- [ ] 在无登录状态和目标移动设备上完成最终验收。

## 5. 收尾

- [ ] 发布说明和 `CHANGELOG.md` 已更新。
- [ ] 版本号、Git tag 和 GitHub Release 与实际交付一致。
- [ ] 确认交付物后预览 `git clean -ndX -- dist` 的结果。
- [ ] 清理 `dist/`、浏览器草稿和不再需要的临时托管制品；确认构建器已移除 `src/generated/`。
- [ ] 再次确认原始保留项目和永久备份没有被修改。
